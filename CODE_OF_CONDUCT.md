# Código de conducta

Este proyecto sigue el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: trata a todo el mundo con respeto, acepta las críticas constructivas, céntrate en lo que es mejor para la comunidad y no toleres el acoso de ningún tipo.

Para informar de un problema, contacta con la persona que mantiene el proyecto a través de su perfil de GitHub ([@SaiberVid](https://github.com/SaiberVid)). Todas las denuncias se revisarán con confidencialidad.
