# Claude Cert Duel

Duelo en directo para practicar certificaciones de Claude (CCDV-F, CCAR-F, CCAR-P) con amigos.

- Abre la página, escribe tu alias y pulsa **Crear sala en directo**.
- Pasa el código de 4 letras a tu compañero: lo escribe en **Entrar con código**.
- Modos: simultáneo (acierto + rapidez) y por turnos con robo.

Todo funciona en el navegador: conexión directa entre jugadores (WebRTC vía PeerJS) y resultados guardados en cada dispositivo. Sin cuentas ni coste.

Las preguntas son de práctica (originales y bancos comunitarios con licencia MIT), no preguntas reales del examen.
